# Security

Report suspected vulnerabilities privately using the email channel listed on [Lumen's contact page](https://lumen-lime.vercel.app/legal/contact). Use the subject `Lumen security report` and include the affected page or component, the impact you observed, and steps to reproduce with your own test account. Do not publish exploit details in an issue.

Do not send credentials, access tokens, personal information, or database exports. Do not test destructive behavior, bypass moderation, or access other users' data on the live service. The [development guide](docs/engineering/development.md) explains how to run isolated tests.
